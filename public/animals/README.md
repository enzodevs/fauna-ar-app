# Imagens dos Animais

Esta pasta contém as imagens dos animais para a seção "Espécie em Destaque do Dia".

## Como adicionar imagens:

1. Baixe imagens de animais de fontes como:
   - [Unsplash](https://unsplash.com/s/photos/wildlife)
   - [Pexels](https://www.pexels.com/search/animals/)
   - [Pixabay](https://pixabay.com/images/search/animals/)

2. Nomeie os arquivos com o nome do animal em inglês (minúsculo):
   - `cheetah.jpg`
   - `lion.jpg`
   - `elephant.jpg`
   - `giraffe.jpg`
   - `tiger.jpg`
   - `panda.jpg`
   - `leopard.jpg`
   - `gorilla.jpg`

3. Coloque os arquivos nesta pasta.

Se uma imagem não for encontrada, o sistema usará automaticamente o logo do app como fallback.
